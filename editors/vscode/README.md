# Arcod для VS Code

Подсветка, дополнение и проверки для `*.arc` — спецификаций
[Arcod](https://github.com/chubakur/arcod).

## Что внутри

- **Подсветка** (TextMate): объявления, операции, эффекты, провайдеры,
  возможности, типы, длительности, строки и комментарии. Провайдеры
  (`ollama`, `redis`, `yandex`) отличаются от возможностей (`llm`, `kv`):
  это разные оси, и цвет тоже разный.
- **Дополнение по контексту**: после `uses store:` — возможности, после
  `bind x ->` — провайдеры, после `deploy` — провайдеры развёртывания,
  значения `layout`, `overlap`, `catchup`, `onFail`, `trigger`. Плюс типы,
  ошибки, сервисы и операции из текущего файла.
- **Сниппеты**: `service`, `op`, `workflow`, `environment`, `uichat`,
  `effects` и другие.
- **Проверки**: `arcod check --json` на открытии и сохранении, ошибки и
  предупреждения в Problems, счётчик в статус-баре. Ошибки разбора тоже
  показываются, с позицией.
- **Outline**: модуль, сервисы, операции, workflow, типы, окружения.
- **Команды**: проверить, план, собрать, `make`, развёртывание, провайдеры.

## Установка

```bash
cd editors/vscode
npm install
npm run compile
npx @vscode/vsce package --no-dependencies
code --install-extension arcod-0.1.0.vsix
```

## Настройки

| настройка | по умолчанию | смысл |
|---|---|---|
| `arcod.path` | `arcod` | путь к CLI; если пусто — берётся `bin/arcod.mjs` из рабочей папки |
| `arcod.checkOnSave` | `true` | проверять при сохранении |
| `arcod.checkOnType` | `false` | проверять по мере ввода (с задержкой) |

## Ограничения

- Языковой сервер не поднимается: проверки — это вызов CLI, поэтому
  `arcod` должен быть доступен (PATH или `arcod.path`).
- Быстрых исправлений нет: диагностика показывает код и подсказку, но
  не переписывает спеку.
- Подсветка не знает семантики: `send` как имя операции и `send:` как клауз
  различаются по двоеточию, а не по разбору.
