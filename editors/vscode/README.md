# Arcod для VS Code

Подсветка, дополнение и проверки для *.arc — спецификаций
[Arcod](https://github.com/chubakur/arcod).

## Что внутри

- **Подсветка** (TextMate): объявления, операции, эффекты, провайдеры,
  возможности, типы, длительности, строки и комментарии. Провайдеры
  (ollama, redis, yandex) отличаются от возможностей (llm, kv): это разные
  оси, и цвет тоже разный.
- **Языковой сервер** (LSP): расширение поднимает arcod lsp и говорит с ним
  по протоколу Language Server. Вся семантика — от настоящих lexer/parser/check
  компилятора, а не от регулярных выражений:
  - **Диагностика** — в реальном времени по мере ввода (тот же arcod check).
  - **Дополнение** — ключевые слова, типы, сервисы, операции, ошибки, enum'ы,
    алиасы uses. Мёртвые ключевые слова v0.1 (policy, change, since, …) не
    предлагаются.
  - **Outline** (структура) — модуль → сервисы/типы/воркфлоу/ui/окружения →
    операции.
  - **Переход к определению**, **поиск использований**, **hover** с текстом
    объявления.
  - **Форматирование** — каноническая форма через arcod fmt.
- **Команды**: Arcod: проверить (check), показать план (plan), собрать
  (build), собрать всё (make), deploy, providers — запускаются в терминале.

## Настройка

- arcod.path — путь к бинарнику arcod. По умолчанию ищется bin/arcod.mjs
  в корне workspace, затем arcod из PATH. Для LSP добавляется подкоманда lsp.

## Требования

- Node ≥ 24 (сервер исполняет TypeScript нативно, без сборки).

## Другие редакторы

Сервер — это обычный LSP: Neovim (lspconfig), JetBrains, Emacs и другие клиенты
подключаются к arcod lsp тем же протоколом. См. README репозитория.
