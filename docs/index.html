Arcod is a language and a compiler for agent-built services. You write one .arc file — types, operations, errors, rules, effects, bindings — and get routes, adapters, an OpenAPI contract, a UI, tests, deploy manifests and prompts a small local model can actually follow. No library shopping, no drift between the model and the code.

CHECKED, NOT GUESSED

Rights are declared, not hand-written

auth op, roles: and owner: id become a guard in the runtime: 401 for anonymous, 403 for the wrong role or somebody else's record, 404 when the record is gone. A046–A049 catch a guard with no actor source or a role outside the service vocabulary.

LIVE, NOT POLLED

One page, a websocket, zero idle traffic

The service publishes an event after every mutation and the page reads state. A slide reaches the phones in 13–17 ms, and an idle room sends nothing at all; polling every 3 s would keep every phone talking all session.

what shipped this week

Three things shipped on 2026-11-25.

Each is covered by tests in the repository.

2026-11-25 · COMPILER

A field called toString is a field

Every name an author writes is a string key in lookup tables and generated objects, and JavaScript answers a missing key with an inherited member. So a type named toString reached a prompt and a DDL as function toString() { [native code] }, a table of that name failed to migrate, a __proto__ field was stored and migrated but silently missing from OpenAPI, and a provider "resolved" to a function. Lookups now ask for an own key (Object.hasOwn), maps keyed by a model name are built with Object.create(null), and such keys are written with defineProperty — in prompts, migrations, dialects, GraphQL, providers, OpenAPI and both SQL stores. __proto__ declared as a name is A102: an error at check time, not a crash at build time.

2026-11-25 · EDITORS

A language server that answers in JSON-RPC

arcod lsp speaks to VS Code, Neovim and JetBrains over stdio. A method it does not serve is now -32601, a body that is not a request is -32600, and params it cannot read are -32602 — the client's log names the failure instead of showing a null. A request sent as a notification gets no response, after shutdown only exit is served, and exit without shutdown is exit code 1. A CRLF document keeps its diagnostic line numbers and still formats with a valid range.

2026-11-25 · POSTGRES

One bad statement no longer kills the connection

The Postgres client had a single socket and destroyed it on any error frame, so after one failed statement the queue and /healthz waited on a dead connection forever. The error now belongs to the statement in flight: a duplicate insert arrives at the body as the declared Conflict (409) and the next query answers on the same socket. An aborted transaction is recovered by ROLLBACK, a socket the server closes on idle reconnects, and a reconnect does not run the migrations twice.

why another tool

The model and the code are two descriptions of one thing.
They drift.

Arcod removes the second description. What cannot be checked — is not allowed to be guessed.

No library shopping

The model names a capability (kv, sql, llm, stream), the environment names a provider. The compiler knows the adapter and refuses a provider that does not implement the capability.

Prompts a 7B model can follow

One prompt per operation, derived from the contract: 66–109 tokens instead of a service description. Constant rules live in the system prompt, so the model never re-invents the framework.

Unresolved is a failure

If a step cannot be derived from effects and type shapes, generation stops with unresolved instead of quietly inventing code. Unhandled errors, unused bindings and unknown clauses are diagnostics, not surprises.

the pipeline

One file in. A running system out.

arcod make runs the same steps the standalone commands do, so the pipeline cannot drift from the CLI.

examples/onetimemessage/main.arc
service OneTimeMessage : http {
  uses store: kv(ttl: 999s)
  uses uuid: ids

  contract {
    public op create(body: Body) -> MessageId {
      route: "POST /api/messages"
      effects: store.set, uuid.new
      errors: Invalid
      on error Invalid: body != null
    }

    public op read(id: MessageId) -> Body {
      route: "GET /api/messages/:id"
      errors: NotFound, Gone
    }
  }

  rules {
    invariant read.at_most_once: once(read, by: id)
    atomic read { get; del }
  }
}

what you get

Everything the service needs, derived from one source.

Not snippets to paste — artifacts that run, and that the compiler keeps honest.

Records, not blobs

A record type is a store. rules { unique Task.title } is a claim the adapter keeps: the second task with that title is the declared Conflict, not a 500. io.find takes where, order, limit and a keyset cursor, so a page does not shift under inserts.

Defaults that hold everywhere

done: bool = false is written once and honoured by the migration (DEFAULT 0), by io.insert (only missing fields are filled, an explicit null wins) and by the OpenAPI schema (default, field no longer required). A default declared after rows already exist fills on read as well: fetch, find, a where filter, order and an aggregate all see the declared value on a row that never stored it.

Input checked at the boundary

email, url and declared enums carry format into OpenAPI and a validator into the generated service: a value that breaks the declaration never reaches the operation body.

Migrations from the model

arcod migrate turns record types into typed tables — uuid as CHAR(36), unique rules as UNIQUE KEY — with a checksummed changelog the service applies on boot. Re-runs are no-ops; an edited migration refuses to start.

Totals and sums in one call

io.count returns a number and ignores limit/cursor; io.aggregate(entity, { field, op }) returns sum, avg, min or max over one numeric field with the same where operators as find. On SQL each is one statement, on kv one fold of the filtered namespace; the effect is declared as store.count or store.aggregate.

One row, one shape on every driver

The generated store checks a write against the record it declares before either driver sees it: a boolean field refuses "false", an int refuses 1.5, a text or bytes field refuses a number, a datetime refuses a word, a patch cannot change the id, and a field the entity does not declare names the ones it does. Declared bounds travel with the same check, so string(min: 3, max: 5) is a 400 on insert and on update.

One model, two SQL dialects

arcod build --dialect postgres emits a PgStore and Postgres migrations from the same model; MySQL remains the default output. A build speaks one dialect: a DATABASE_URL of the other scheme stops startup with a named error instead of failing later.

Observable without a stack

Every service logs one JSON access line per request, echoes and propagates x-request-id, and serves /metrics in Prometheus format — RPS, latency histogram, errors, in-flight and capability calls. Timeouts come from ARCod_TIMEOUT_MS, and a HEAD probe is answered by the GET route with the same headers and no body.

Contracts that become behaviour

atomic read { get; del } becomes a Lua script; once(read, by: id) becomes a tombstone key returning Gone. budget { concurrency: 8 } becomes a 503 limiter. A saga step with compensate: runs its undo in reverse when a later step finally fails.

Embeddings as an effect

io.embed(texts) returns one vector per input from the bound llm provider — no SDK in the service, no vendor in the model. The binding may declare dim, and a vector of another width fails the operation with a named error. examples/vector stores each note with its vector and ranks search hits by cosine in the body.

UIs without a frontend decision

Forms from public operations, layout: chat for dialogue, layout: presentation for decks: a join code, a QR encoder vendored into the page, and slide changes pushed to every phone. A field follows its declaration: an enum is a select of the accepted values, email/url are native inputs, numeric bounds become min/max.

Pages the service can serve itself

render: ssr embeds the page in the service and fills its first screen in-process, so the HTML arrives with data. Compose drops the nginx sidecar and the k8s ingress points at the service; the static files are still written for a separate front door.

Someone else's service, still typed

external service Ledger { ... } gives a remote client typed by a partial contract; the address comes from the environment, never from the body.

A contract others can read

arcod openapi prints OpenAPI 3.1 on stdout: canonical paths from route, schemas from types, status codes from the same error mapping the runtime uses, and the model's examples as named examples. A service with auth: identity publishes a bearerAuth scheme and lists the token only on operations that need it; access clauses travel as descriptions. No server, no host, no provider in the document.

Deploy as a declaration

deploy docker | aws | yandex | kubernetes produces compose or a deploy.<env>.json manifest with "executed": false — no credentials, no API calls behind your back. arcod terraform renders the same environment as Yandex Cloud HCL — network, managed Postgres/Redis, bucket — with every credential a sensitive variable.

A build you can automate

arcod build --json reports the result as one object: mode, directory, dialect, port, reference, files, images and body sources. The tree is published atomically — a late failure leaves the previous .arcod/build untouched — and migrations, prompts and SQL the contract no longer owns are pruned.

JSON on failure, not only on success

--json is not a promise only the happy path keeps: build, test, migrate, prompts, impl, deploy and run --detach answer one object on stdout. A refusal names error and the reason; a spec that does not check answers its diagnostics in the same payload, and the exit code still says what happened. Without the flag the human text is unchanged, so the machine never gets prose.

A filter refuses what cannot mean anything

contains on a bytes, datetime or decimal field is an Invalid naming the operator, not a text search that happens to match; a range comparison must name a scalar field; a list or record field cannot be an order key; and a record field compares by value, so the key order in the filter does not decide the match.

A formatter that keeps your comments

arcod fmt prints the canonical form — one style, one AST, one output — and a comment stays attached to the declaration, field, clause or block it was written in, including the last one in a body. A second pass over its own output changes nothing, so fmt --check is safe in CI.

Bodies held to the same contract

An operation body is impl/<op>.mjs, and check reads it as strictly as the spec: it has to export async function <op>(input, io). A body with nothing to rename is A096 — an error, so build refuses with the file and line — while a file that matches no operation is W049 and an operation left without a body is W050: warnings that name the file and the operation. Bodies share one module, so a helper goes in impl/lib.mjs — bundled once before the bodies, called as a top-level name by every body, and refused as A093 when a body redeclares it.

Names your model chooses, not names JavaScript owns

An operation, a field, a type or a provider is a string key in the compiler's tables and in the code it emits. A key that is absent is answered by Object.prototype, so toString or __proto__ used to reach generated metadata as an inherited member. Reads check ownership, maps keyed by model names are built without a prototype, and declared keys are written with defineProperty; nine test files name the member (toString, constructor, hasOwnProperty, valueOf, __proto__) and assert the fallback or the published key, not just that nothing crashed.

What does not work yet

  • Scaffold without bodies answers 501 NotImplemented for every operation; a build is contracts, routes and adapters until bodies come from --impl or your own code.
  • Bodies are loaded from impl/<op>.mjs only. A body written in a .js or .ts file next to the .mjs ones is not read: W051 names that file, so it is not mistaken for a silent W050.
  • The Postgres runtime is proven against a fake wire backend and an end-to-end example, not yet against a live managed server in CI. MySQL remains the default build.
  • OLAP, metrics, secrets and friends are provisioned in compose but have no effect signatures; Kafka and RabbitMQ provision a queue the adapter cannot speak — bind queue to Redis.
  • find on kv is a scan with a filter, not a query planner: one entity namespace matched in memory. On sql the same find is pushed into WHERE/ORDER BY/LIMIT. Indexes are single-field (index Task.dueAt); composite and partial indexes are not generated.
  • Vector search is a scan. examples/vector reads the notes it can find and ranks them in the body: there is no ANN index and no distance order by in the store. Cosine scores stay between -1 and 1, so a caller can pick a threshold; a large corpus needs an index this example does not have.
  • SSR embeds one first screen. A page whose operations all need input cannot fill it and gets W030; later changes still come from the generated form, not from streamed updates.
  • datetime keeps milliseconds on SQL. A datetime column is DATETIME(3), so a timestamp written with six fractional digits reads back trimmed on MySQL while kv keeps the string as sent; sub-millisecond precision is not preserved across drivers.
  • A unique claim on kv outlives the record: the claim key has no TTL, so an expired record holds its value until removed or updated. On sql, uniqueness is the table constraint, so nothing to clean up.
  • Workflows are parsed, described and validated — no runner is generated (W022); a job runs only when it declares an on: queue consumer (W017).
  • Streams and queues are in-process until you bind them to Redis; only then do replicas share events. OpenAPI publishes a bearerAuth scheme for a service that uses auth: identity, and the token requirement is listed only on operations that need it; a public operation opts out with security: [].
  • arcod fmt re-lays out a record type on one line — it is a canonical printer, not a style-preserving one; the comment survives, your line breaks do not.
  • __proto__ is refused as a name, toString is not. A102 stops only the name the generated metadata maps cannot carry; constructor, valueOf and friends stay legal and are safe because every lookup is an own-key read. That rule lives in each emitter, so a new one is held to it by a test, not by check.
  • JavaScript only. PHP, Go and Python would be separate emitters.
  • arcod terraform targets Yandex Cloud only and renders no state backend; terraform validate is not part of CI yet.

What that buys you

  • Every claim above has a diagnostic code, a test, or a note in the README.
  • No silent fallbacks: an underivable step fails with unresolved.
  • No cloud calls: the default model endpoint is local and a remote one is refused without --allow-remote.
  • No hidden dependencies: the emitted service and page are single files, including the RESP client and the QR encoder.
