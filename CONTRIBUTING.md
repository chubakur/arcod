# Contributing to Arcod

Thanks for taking the time to contribute.

## License of contributions

By submitting a contribution you agree that it is licensed under the
Apache License, Version 2.0 (see `LICENSE`), and you certify the
Developer Certificate of Origin below.

## Sign-off (DCO)

Every commit must carry a sign-off line:

```
git commit -s -m "feat(...): ..."
```

This adds `Signed-off-by: Your Name <you@example.com>` to the message.

```
(a) The contribution was created in whole or in part by me and I have the
    right to submit it under the open source license indicated in the file; or

(b) The contribution is based upon previous work that, to the best of my

    the right under that license to submit that work with modifications,
    whether created in whole or in part by me, under the same open source

(c) The contribution was provided directly to me by some other person who

(d) I understand and agree that this project and the contribution are public

```

Full text: https://developercertificate.org/

## Before you open a pull request

- `npm test` must be green.
- `npm run typecheck` must be clean.
- Keep the change focused; one topic per pull request.
